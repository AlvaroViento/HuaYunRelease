# 画云 HuaYun

在桌面上画一朵会随风飘动的云。

本仓库用于发布 Windows 程序包与版本说明，不包含应用源码。

## 下载与运行

首次使用请前往 [最新版本](https://github.com/AlvaroViento/HuaYunRelease/releases/latest)，下载 Windows x64 ZIP 程序包，解压后双击 `画云.exe`。

适用于带有 .NET Framework 4.x 的 Windows x64 系统，无需安装 Node.js 或 Electron。

## 使用

- 点击“开始画云”，或不按鼠标键快速来回摇动约四次，进入画云模式；横向、竖向、斜向均可。
- 按住左键画一个有面积的轮廓，松开后生成云，最多八朵。
- 单击云朵让它散开回聚；双击让对应云组散去。
- 空白处单击、Esc 或其他按键会退出画云，让所有云散去。
- 关闭面板后程序在托盘待命，退出程序请使用“退出画云”。
- 默认开启当前账户的开机自启，登录后在托盘待命；可在设置中关闭，之后会记住选择。
- 设置中点击“检查更新”，发现新版后点击“立即更新”，程序自动下载、校验、替换并重启。更新失败保留或恢复旧版，个人设置不变。

1.0.0 版本需手动升级一次到 1.0.1，此后即可使用应用内更新。请将程序放在当前账户可写的固定目录。

天气服务需自行配置；未配置时仍可绘画及选择固定云形态。配置和密钥保存在当前账户 AppData 中，不随程序包分发。

程序目前未做代码签名。资源来源说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
